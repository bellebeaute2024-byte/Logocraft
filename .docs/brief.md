# LogoCraft — AI Brand Logo Generator

- One-line positioning: Generate professional logos for brands in seconds using AI
- Target users: Founders, entrepreneurs, designers, and small business owners who need brand logos
- Core features:
  1. Brand details form (name, industry, style, colors, description)
  2. AI logo generation using image model (multiple variations)
  3. Download generated logos in high quality
- Important features (P1):
  1. Style selector (minimalist, modern, vintage, playful, luxury, tech)
  2. Color palette picker (primary/secondary color preferences)
  3. Logo preview panel with zoom and background toggle
- Device strategy: adaptive
- Design style: modern-dark-tech (dark premium SaaS feel with cyan/green gradient accents)
- Technical constraints: Uses GPT Image 2 gen via REACTUS media API for image generation
- Nova Agent: not needed
